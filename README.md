# Elvera Media — Digital Marketing Agency Website

A modern, responsive website built for **Elvera Media**, a digital marketing and creative agency.

This project was designed and developed as a **Computer Science student project**, with a focus on frontend development, responsive UI, component-based architecture, forms, API integration, and real-world deployment.

## 🌐 Live Website

**https://www.elveramedia.in**

## 📌 Project Overview

The goal of this project was to build a professional agency website that presents Elvera Media's services, showcases its work, collects client enquiries, and provides an easy way for visitors to get in touch.

The website was developed from scratch using modern web technologies and was deployed for real-world use.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern agency-style UI
- Hero section with clear call-to-action
- Services showcase
- Portfolio / work showcase
- Client testimonials
- Review submission system
- Contact and lead-generation forms
- WhatsApp enquiry integration
- Google Sheets lead collection
- Responsive navigation
- Smooth UI interactions
- Production deployment with Vercel
- Custom domain integration

## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/ShubhamMali-tech/elvera-media.git
```

Navigate into the project:

```bash
cd elvera-media
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available on the local development server shown by Vite.
